Bug #1 & #2 — 精确修复方案

Bug #1：死人说话
根因：free_discussion 的 speech_order 生成时
未过滤 gs.players[pid].alive == False

修复位置：day.py free_discussion()
speech_order 自动生成时加 alive 过滤

修复代码：
# 旧
speech_order = choose_sheriff_led_order(gs, sid)
# 新
alive = [p for p in order if alive]

同步检查 sheriff_policy.py 中的
choose_no_sheriff_speech_order 和
choose_sheriff_led_speech_order
确保它们也排除已死玩家
Bug #2：猎人开枪崩溃
根因：_dispatch_agent 在 skills.py
resolve_hunter_shot 中返回 dict | None
但调用方把返回值当 dict 对 .get()
实际返回了 list → AttributeError

修复位置：skills.py resolve_hunter_shot
第 ~75 行

修复代码：
# 旧
target = _dispatch_agent(state, fn, pid)
# 新
result = _dispatch_agent(state, fn, pid)
target = result if isinstance(result, str) else None

附加加固：agent_hunter_shot 适配器
确保返回值类型一致性
