# Command: Implement Current Task

1. Read the active task in `PROGRESS.md`.
2. Read relevant design sections.
3. Identify expected files.
4. Make the smallest coherent change.
5. Run relevant checks.
6. Update `PROGRESS.md`.

Rules:

- Do not expand scope.
- Do not change rules based on RAG or memory.
- Do not hardcode provider credentials.
- Do not let agents mutate deterministic game state.
