1. Read `PROGRESS.md`.
2. Read `CLAUDE.md`.
3. Read `docs/design/werewolf-agent-v1-design.md`.
4. Read the current phase plan in `harness/plans/`.
5. State the active task in one paragraph.
6. Do not edit files until the active task is clear.
