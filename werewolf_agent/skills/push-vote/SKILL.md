# 归票

在投票阶段作为领导者引导全场玩家集中投票给一个目标，避免分票导致狼人逃脱或不放逐任何人。

## 何时使用

- **你是警长**：警长拥有归票权，必须在投票前明确给出归票方向
- **你是预言家且查验到狼人**：你有责任引导好人投票给确认的狼人目标
- **场上意见分歧严重**：多人被怀疑但没有统一的投票目标，需要有人站出来统一方向
- **关键轮次（如决赛轮）**：一票之差可能决定胜负，必须确保票数集中

## 何时不使用

- 你的身份可信度很低——此时你的归票没人会跟，反而暴露你的意图
- 信息极度不足——不确定谁是狼就乱归票可能归出好人
- 已经有比你身份更高的人给出了合理的归票方向——此时跟从更有效
- 你是狼人但队友比你更适合作归票位——不要多人同时归票

## 如何使用

1. **明确归票对象**：用简洁清晰的语言说出"我建议今天投X号"
2. **给出归票理由**：基于查验结果、发言矛盾或投票模式说明为什么是他
3. **呼吁统一**：强调分票的危险性——"如果不集中投票，好人可能放逐不了狼人"
4. **回应质疑**：如果有人质疑你的归票，正面回应而不是回避

## 注意事项

- 归票不等于号票——归票是建议，号票是命令，语气要坚定但不独断
- 如果归票目标是好人，可能导致关键好人被放逐——归票前要反复确认判断
- 狼人归票时要注意不要暴露队友——归票目标应为好人
- 警长归票比普通玩家更有分量，警长需要更谨慎
- 归票后要明确列出不计入票的玩家（如已被查验的好人），减少误伤
