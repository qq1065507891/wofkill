# 对跳

针对场上已经起跳的预言家进行正面身份对抗，通过对比查验逻辑、警徽流和发言质量来证明对方是假的。

## 何时使用

- **真预言家对跳悍跳狼**：场上已有悍跳狼起跳，你必须站出来对抗，这是你作为预言家的核心职责
- **狼人对跳真预言家**：前置位已有人起跳预言家且发言较强，你需要从另一个角度质疑他的查验逻辑
- **PK发言环节**：经过一轮平票后进入PK发言，这是对跳双方正面交锋的关键时刻
- **双方查验结果矛盾时**：两人都对同一玩家给出了相反的查验结果，必须有一方是假的

## 何时不使用

- 场上已经出现两个以上的预言家——此时再跳只会让格局更混乱
- 你的可信度已经很低——继续对跳只会加速暴露
- 已有明确证据证明对方是真的（如对方报对了银水/被好人广泛认可）
- 你的角色不是预言家也不是被安排悍跳的狼人

## 如何使用

1. **直接指出矛盾**：对比双方的查验结果、警徽流、发言逻辑，指出对方的具体矛盾点
2. **时间线对比**：你的验人逻辑应该有一条完整的时间线——"N1验X是好人，N2验Y是狼人"
3. **动机分析**：分析对方起跳的动机——如果是狼人悍跳，他的查验逻辑会保护队友
4. **警徽流对比**：对比双方的警徽流逻辑，指出对方警徽流中不合理的选择
5. **呼吁理性判断**：呼吁好人仔细对比双方的发言质量，而不是跟风站边

## 注意事项

- 对跳不是互相辱骂——发言要有逻辑、有条理，让好人能听懂
- 不要同时质疑多个对跳者——聚焦一个目标进行攻击
- 如果对方是悍跳狼，他的查验结果通常会保护狼队友（给队友发金水、给好人发查杀）
- 真预言家对跳时必须展现出"不怕死"的态度——因为狼人不敢刀你（坐实你的身份）
