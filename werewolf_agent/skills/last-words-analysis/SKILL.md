# 分析遗言

对刚出局玩家的遗言进行系统性交叉验证，提取身份线索、阵营信号和隐藏信息。

## 何时使用

- 有玩家刚发表遗言后，需要判断遗言可信度时
- 遗言中包含角色声明（如声称预言家/女巫），需要与其他信息交叉验证时
- 遗言给出了查验结果、银水信息或归票建议，需要评估是否可信时
- 遗言内容与已有公开信息存在矛盾，需要判断哪一方在说谎时
- 狼人需要从遗言中提取神职信息以确定下一刀目标时

## 何时不使用

- 遗言尚未发生或刚开局时
- 遗言为空（沉默离场）或内容过于简短无分析价值时
- 遗言内容与场上局势完全无关时（如纯情绪发泄）
- 狼人夜间讨论阶段——遗言分析应在发言阶段进行

## 如何使用

调用此技能后，系统将自动：
1. 提取遗言中的角色声明、查验信息、银水信息和归票建议
2. 与已知信息（预言家查验、女巫行动、投票记录）进行交叉验证
3. 对比遗言者生前的发言立场和投票行为，判断一致性
4. 输出：遗言可信度评估 + 关键信息提取 + 矛盾点标记

## 注意事项

- 遗言不一定是真话——狼人可能留下假信息继续误导好人
- 遗言者的角色声明需要与其他玩家的声明交叉比对
- 遗言中被杀的预言家通常会说真话（没有继续撒谎的动机），但悍跳狼的遗言会继续骗人
- 遗言中给出的银水/金水/查杀信息价值极高，需要在发言中引用这些信息
