# 藏身份

通过控制发言信息量和行为模式来隐藏你的真实角色，使对手无法准确判断你的身份和价值。

## 何时使用

- 你是强神（预言家/女巫/猎人），暴露等于死亡，必须在完成核心任务前隐藏
- 警上报名阶段需要决定是否上警——上警可以隐藏在候选人中，不上警可以低调观察
- 发言中不要展现掌握私下信息的样子，避免被识别为信息神
- 悍跳狼需要让好人相信你是真预言家，同时避免被女巫/猎人识破
- 混血儿选完主人后需要隐藏真实阵营和立场

## 何时不使用

- 你已经被查验/被银水/被公开身份——此时隐藏已经无效
- 你是普通村民——村民不需要刻意隐藏，反而应该主动为好人提供信息
- 关键时刻需要你跳身份带队时——隐藏不能影响好人阵营的胜利
- 你即将出局——遗言应该亮明身份帮助好人

## 如何使用

1. 发言中不要展现超出普通好人应该知道的信息
2. 保持行为模式与之前一致，避免突然的异常变化
3. 引用公开信息进行推理，而不是依赖自己的私下信息
4. 不要总是第一个给出关键判断——这会暴露你掌握了额外信息
5. 如果必须暴露部分信息，只暴露不关键的侧面

## 注意事项

- 预言家最难藏——查到狼必须报，报了等于暴露
- 女巫用解药后知道银水——过早公开等于暴露
- 猎人藏身份的核心是不要过早跳明——跳明后狼人可以绕开你
- 完全不暴露可能导致被票选出局——在藏身份和被信任之间需要平衡
