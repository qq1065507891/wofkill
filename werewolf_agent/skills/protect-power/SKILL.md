# 神职降压

在发言和投票中通过轻度站边、质疑冲票逻辑、分散讨论焦点，降低已暴露或疑似暴露神职被狼人精准定位的风险。这是社交发言降压，不是夜间技能。

## 何时使用

- 预言家已起跳，需要分散狼人注意力
- 女巫已暴露或即将暴露——女巫是唯一能救人的角色
- 已确认某玩家是强神，发言中不要过多讨论其神职特征
- 疑似强神的玩家被狼人围攻——站出来分散火力
- 猎人未暴露——不要逼迫猎人跳身份，让他在暗处更有威慑力

## 何时不使用

- 你明确知道某人是悍跳狼在假装神职——不需要替他降压
- 你已经被查验/明牌——你的保人言论反而让狼人更关注目标
- 目标已公开身份且被广泛认可——不需额外降压
- 神职降压与当前归票目标冲突——需要权衡优先级

## 如何使用

1. 分散注意力：当狼人集火强神时，主动引导讨论转向其他方向
2. 模糊身份信息：避免在发言中确认或暗示某人可能是神职
3. 社交降压：用公开发言逻辑解释为什么不应机械冲票该玩家
4. 投票取舍：不要让你的票被狼人用来冲票疑似神职

## 注意事项

- 过度保人反而暴露目标——保持自然
- 神职优先级：预言家 > 女巫 > 猎人 > 白痴
- 如果神职已被狼人锁定，额外降压意义有限
