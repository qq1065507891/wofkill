# 冲票

狼队在投票阶段协同一致，集中所有狼人的票数投向同一个好人目标，利用人数优势强行放逐好人。

## 何时使用

- **狼人数量占优或持平**：当狼人票数足以影响投票结果时，集中冲票可以强行出人
- **需要紧急出掉一个关键好人**：如真预言家、已验明的好人、或者威胁极大的强神
- **分票局中浑水摸鱼**：当好人内部意见不统一时，混入投票潮中推波助澜
- **PK轮次需要确保对面的好人出局**：在PK发言后，所有狼人统一投票给好人对跳者

## 何时不使用

- 狼人数量明显少于好人——此时冲票无法改变结果，反而暴露所有狼人
- 冲票目标明显是好人而你是明狼——会坐实你的狼人身份
- 有队友在倒钩位——倒钩位的队友不应该参与冲票，保持"好人"形象
- 投票过于集中可能被复盘分析——狼队需要适当分散票型

## 如何使用

1. **预沟通**：在狼队夜间讨论中确定冲票目标和配合策略
2. **分散入场**：不同狼人用不同理由投票给同一个目标，显得各有独立判断
3. **不要同时投票**：避免所有狼人在同一时间投票，减少被注意的风险
4. **准备发言支撑**：投票后要有合理的公开解释，不要让投票看起来完全是跟风

## 注意事项

- 冲票是最容易暴露狼队的操作——投票记录会被复盘
- 如果冲票失败（好人没有被放逐），狼队将在后续轮次面临巨大的票型压力
- 倒钩位的队友绝对不能参与冲票——他们的"好人"身份是狼队的长期投资
- 冲票前要计算票数——确保狼队票+摇摆票能达到多数
