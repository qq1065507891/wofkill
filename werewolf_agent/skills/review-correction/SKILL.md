# 复盘纠错

一局游戏结束后，系统性回顾关键判断节点，识别导致错误决策的原因，从中提炼可改进的策略思路。

## 何时使用

- 游戏结束后的复盘阶段（review phase）
- 你想分析自己整局的表现，找出判断失误的根本原因
- 你想理解为什么某个关键轮次做出了错误决定
- 你想为未来的对局积累经验教训

## 何时不使用

- 游戏还在进行中——复盘分析应该留到游戏结束后
- 你当前还有行动需要执行——优先完成游戏内的决策

## 如何使用

调用此技能后，系统将引导你回顾：
1. 关键判断点：回顾每个关键轮次的决策依据
2. 错误识别：定位哪些判断被后续信息证明是错误的
3. 原因分析：分析为什么当时做出了那些错误判断（信息不足？被误导？逻辑漏洞？）
4. 改进建议：提出未来对局中如何避免类似错误的具体建议

## 注意事项

- 复盘不是自我批评——目的是学习，不是责怪
- 重点关注\"可操作\"的改进点，而不是笼统的\"下次要更仔细\"
- 需要考虑当时的信息条件——不能以\"事后知道结果\"来批判\"当时的判断\"
