# 倒钩

狼人在好人阵营中长期潜伏，通过表现得像一个"独立思考的好人"来建立信任，在关键时刻发挥作用。

## 何时使用

- **开局时被指定为倒钩位**：狼队夜间讨论中明确了你的战术角色
- **需要深度渗透好人阵营**：当正面冲突（悍跳/冲锋）难以取胜时，转向长期渗透
- **队友已经暴露或即将暴露**：你的"独立质疑"可以让你在队友出局后更像好人
- **需要获取关键信息**：作为"好人"被信任后，更容易获取预言家查验目标等信息

## 何时不使用

- 狼队已经在正面战场取得优势——此时不需要长期潜伏
- 你是被安排悍跳的狼人——悍跳和倒钩是冲突的角色
- 你已经在前几轮投票中暴露了狼人身份——倒钩已经无效
- 游戏轮次接近尾声——倒钩是一个长期策略，晚期无意义

## 如何使用

1. **建立独立思考形象**：发言要有自己的逻辑，不要完全跟风任何一边
2. **适度攻击队友**：在发言中轻踩狼队友（但不要用力过猛导致队友出局）
3. **投票与队友差异化**：偶尔在不关键轮次投出与狼队不同的票，增加"好人感"
4. **保持一致性**：你的立场和行为逻辑要在跨轮次中保持一致，不能前后矛盾
5. **在关键时刻反水**：当所有人都信任你时，在决胜轮投出关键一票

## 注意事项

- 倒钩是最难扮演的狼人角色——需要在高压力下长期维持"好人"形象
- 攻击队友要适度——如果因为你导致队友被放逐，狼队数量下降
- 如果倒钩位暴露，之前建立的所有信任瞬间崩塌
- 倒钩位通常不应该活到最后——"为什么你还活着"是最大的破绽
- 普通预言家查验狼人时结果仍是狼人，不会把你验成好人；只有悍跳者公开发出的假金水才可能暂时抬高信用
