# 抗推

当你成为放逐目标时，通过有说服力的防守发言澄清质疑、转移焦点或提供有价值的最后信息。

## 何时使用

- 你被多人点名怀疑或投票，需要立即组织有效防守
- PK环节你即将被票选，必须比对面的玩家更有说服力
- 你是好人但被诬陷，需要通过逻辑和证据洗清嫌疑
- 你是即将被放逐的狼人，遗言中尽可能制造混乱或保护队友

## 何时不使用

- 质疑力度很轻（只有一两个人随口提了一句）——过度反应反而引起注意
- 你是狼人且已被查验确认——抗推无效，考虑自我牺牲保护队友
- 场上已有明显的票选目标——不要主动跳出来成为新焦点
- 你的角色是白痴——被放逐对白痴有利（亮身份不死），不需抗推

## 如何使用

1. 正面回应质疑：不要回避或转移话题，直接回应每一个质疑点
2. 重建逻辑链：从头梳理发言逻辑和投票理由，证明行为一致性
3. 指出替代目标：给出你怀疑的玩家和具体理由
4. 利用已有信息：引用预言家查验、女巫银水、公认的好人来支撑防守
5. 表达好人立场：如果出局，给出最后分析帮助后续好人

## 注意事项

- 好人的抗推应该"越来越清晰"，狼人的抗推往往"越来越混乱"
- 不要攻击已被证明的好人——这会直接坐实你的可疑
- 如果确实无法挽回，把最后发言留给好人阵营
- 遗言中狼人可报假身份、假查验制造混乱
