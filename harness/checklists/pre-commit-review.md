# Pre-Commit Review Checklist

Before claiming work is done:

- [ ] Re-read the active task in `PROGRESS.md`.
- [ ] Confirm only the active task was changed.
- [ ] List all changed files.
- [ ] Run relevant tests.
- [ ] Run formatting or linting if available.
- [ ] Check changed behavior against `docs/design/werewolf-agent-v1-design.md`.
- [ ] Update `PROGRESS.md`.
- [ ] Record commands run and results.
- [ ] Record risks or skipped verification.
- [ ] Do not claim completion if tests were not run without saying so.
