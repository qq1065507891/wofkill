# V1.1 Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the current V1 prototype into a stronger local hardening baseline without forcing production infrastructure into the default developer path.

**Architecture:** Add local, testable adapters around runtime execution, provider smoke tests, timers, MCP transport, RAG storage, and production storage boundaries. Keep deterministic `RuleEngine` and event replay as the source of truth; new infrastructure may schedule, call, or persist work, but must not adjudicate game rules.

**Tech Stack:** Python, pytest, FastAPI, LangGraph, Pydantic, SQLite, optional external providers via environment variables, optional future Redis/PostgreSQL/Qdrant/pgvector adapters.
